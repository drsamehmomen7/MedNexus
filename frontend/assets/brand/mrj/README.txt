MRJ Icon Asset Pack

Included in this package:

1) icon_only/png
   Transparent icon-only exports in multiple sizes.

2) app_icon/png
   Rounded-square app icon exports in multiple sizes.

3) monochrome/png
   Single-color monochrome icon exports.

4) icon_only/jpg and icon_only/webp
   Flat-background exports for documentation and presentations.

5) app_icon/jpg and app_icon/webp
   Rounded-square exports for previews and mockups.

6) favicon
   favicon.ico plus 16x16 and 32x32 PNGs for web use.

Recommended usage:
- Desktop/mobile app icon: app_icon/png/MRJ_app_icon_1024.png
- Website favicon: favicon/favicon.ico
- Transparent documentation use: icon_only/png/MRJ_icon_1024.png
- Monochrome print use: monochrome/png/MRJ_icon_mono_1024.png
