# R5.0A — Radiology VISUALIZE V0

**Status: CLOSED FOR HORIZONTAL PROGRESSION. Functional/scientific acceptance: PASS. Final visual UX acceptance: DEFERRED.** This is a functional Stage 06 in the existing seven-stage Journey. R4.0A ANALYZE V0 is closed. Unified Journey UX is deferred until the complete seven-stage flow is functional.

## Purpose and authority

ANALYZE computes report-level collection metrics. VISUALIZE presents one completed, immutable `AnalysisRun`; it does not read source reports, protected text, raw engine entities, or canonical facts to create new analysis. The persisted AnalysisRun is the sole numerical authority for eligibility, identity, assertion, numerator, denominator, frequencies, distributions, co-occurrences, and coverage. Stage 06 copies a bounded whitelist of presentation-safe values. Formatting a supplied `value` as a percentage and scaling a zero-based graphic are display operations, not new clinical calculations. A visualization is descriptive, never prevalence, incidence, risk, association, correlation, or causation.

The input is the R4.0A `mrj-radiology-analysis-v0.4` AnalysisRun, including its collection name/ID/version, policy, diagnostics, presentation-limited repeated co-occurrences, summary, and provenance. Older analysis contracts are rejected and must be reanalyzed rather than silently interpreted. The `POST /api/v1/understanding/analysis-runs/{analysis_run_id}/visualize` endpoint returns a persisted `mrj-radiology-visualization-v0.2` `VisualizationRun`; `GET /api/v1/understanding/visualization-runs/{visualization_run_id}` reads it back. Runtime JSON resides in the external `Analysis_Workspace/visualizations` directory, outside Git.

`VisualizationRun` contains deterministic `visualization_run_id`, source `analysis_run_id`, collection ID/version/name, source-derived `generated_at`, configuration, analysis policy, collection summary, ordered panels, and source-analysis provenance. `generated_at_basis=ANALYSIS_RUN_GENERATED_AT` states why the timestamp is stable. A panel records ID, title, subtitle, type, source metric section and row references, copied data, denominator context, filters, empty state, warnings, accessibility description, and default row limit. The same AnalysisRun and V0 configuration produce the same specification and ID. The external store returns the same bytes on repeat requests. No second filtering engine or chart library is introduced; an operator changes filters in ANALYZE, which creates a new AnalysisRun for VISUALIZE.

## Deterministic panel policy

Panels are always ordered as Collection Snapshot, Top Findings, Diagnostic Considerations, Pertinent Negatives, Measurements, Stratification, Report Year, Co-occurrence, Data Coverage, and Standardization Coverage. Snapshot copies total/included/excluded/review report counts and canonical fact count. Findings use ranked PRESENT finding rows; the first ten appear by default and additional rows are available in a native keyboard-accessible expansion. Anatomy, laterality, and analytical concept identity stay visible. Diagnostic considerations have their own panel and retain `FAVORED`, `POSSIBLE`, `LESS_FAVORED`, `LESS_LIKELY`, or the supplied hypothesis status. Pertinent negatives have a separate documented-absence panel. Neither becomes a positive finding.

Measurements use a table of ANALYZE-approved comparable distributions, retaining measurement type, dimension, unit, sample count, minimum, maximum, mean, median, and report denominator. V0 deliberately has no histogram: AnalysisRun does not supply governed bins, and VISUALIZE does not manufacture them. If `INSUFFICIENT_COMPARABLE_MEASUREMENTS` is present, the panel abstains. Categorical stratification copies ANALYZE buckets, including `MISSING`; a zero-based report-year line is shown only when at least two governed year buckets exist. The series has an adjacent textual list of exact year/numerator/denominator/value pairs. Without that input, it shows `MISSING_TEMPORAL_DATA`.

Co-occurrence uses **only** R4.0A's repeated-pattern projection (minimum support 2 included reports, top 20). One-off pairs remain in the AnalysisRun but do not populate Stage 06. Its no-pattern state says no *repeated* pattern was observed. Coverage bars show available and missing counts for every structured field, with the included-report denominator. Standardization is a terminology-coverage table of whole-fact `MATCHED`, `NEEDS_REVIEW`, and `UNMAPPED` counts, with the canonical-fact denominator; component mappings are separately labeled and never counted as whole-fact matches. `UNMAPPED` is not presented as a clinical failure.

Every frequency or coverage mark has a visible numerator, included-report denominator, and percentage derived solely by formatting the supplied AnalysisRun `value`. Native progress bars start at zero; they are paired with full text and do not rely on color. Tables remain horizontally scrollable on narrow screens, panel grids collapse responsively, long labels wrap, and controls use native buttons/details for keyboard access. A textual description accompanies every panel. Empty states explicitly distinguish no included reports, no findings, no hypotheses, no negatives, unsafe measurements, no repeated co-occurrence, and missing temporal data. No empty graphic is drawn on a zero denominator.

The inclusion policy appears above all panels. When review-required records are explicitly included for validation, Stage 06 states the count and says this **does not imply human review**. Filters are displayed exactly as inherited from AnalysisRun. The collapsed provenance section shows visualization and analysis IDs, collection ID/version, source-derived generated time, and policy. A Journey document receives Stage 06 status only when its attached Stage 05 result has the exact source AnalysisRun ID; re-running upstream EXTRACT, STANDARDIZE, or ANALYZE invalidates the dependent Stage 06 projection. The interface can return to ANALYZE without recomputation.

## First validation and limits

The first view uses the existing `R4.0A Synthetic Radiology Validation Collection`, version 1, and its explicit validation AnalysisRun with eight review-required reports. It creates no new collection. Examples such as cerebral atrophy, atherosclerosis, favored metastatic tumor, documented negative aspiration, and modality/body-region/date coverage come from the saved AnalysisRun; no values are hard-coded. The same cohort has no safely comparable measurement distribution and no repeated co-occurrence, so those panels abstain. Conservative zero-included analysis likewise produces no numeric chart.

V0 has no patient-level denominator, histogram bins, network visualization, cross-report causal narrative, statistical inference, or Stage 07 indicator. Source evidence and clinical interpretation remain outside VISUALIZE. The final visual hierarchy, navigation, and unified Journey experience are deferred.

## Functional closure and deferred work

R5.0A is accepted for horizontal progression on its contract, scientific safety, regression, and live Stage 06 verification. **ANALYZE COMPUTES. VISUALIZE PRESENTS.** Stage 06 does not independently determine report eligibility, numerator, denominator, clinical identity, assertion, hypothesis status, measurement comparability, or co-occurrence semantics. Every view remains traceable through its VisualizationRun ID, AnalysisRun ID, collection ID/version, and inherited analysis policy. Functional acceptance is not final visual design acceptance.

The platform UX review remains deferred until Stage 07 is functional. Its recorded debt covers overall visual hierarchy, typography scale, spacing, page length, stage-to-stage inconsistency, duplicated controls, collection workflow clarity, visible internal IDs and hashes, navigation, report-versus-collection transition, Seven-stage coherence, final responsive behavior and chart design, and a shared Public Health/Radiology platform identity. This closure changes none of those areas.

The next milestone is **R6.0A — INDICATORS V0**. ANALYZE produces descriptive metrics and VISUALIZE presents them; INDICATORS will define governed measurable constructs with explicit indicator identity, purpose, analysis level, numerator and denominator definitions, eligibility, exclusions, time window, stratification context, data coverage, provenance, and validity/readiness state. Stage 07 is not implemented by R5.0A.
